# 📚 Library Management System

A simple console-based Library Management System developed in **C++** using structured programming concepts.

## Features

* Admin & User Authentication
* Book Management (Add, Delete, View)
* Book Borrowing System
* Search Books by Title
* Borrowing History
* Data Persistence using Text Files

## Concepts Implemented

* Struct
* Vector
* Recursion
* Sorting
* Searching
* Pointer
* File Handling

## Storage

The application stores data locally using:
* `admin.txt`
* `user.txt`
* `buku.txt`
* `riwayat.txt`

* C++
